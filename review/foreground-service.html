Remote Hub: connected-device service

Release 2.1.2 (35), package com.remotehub.universal.tv.remote. This recording uses the actual signed release APK on an Android 15 emulator and a simulated Roku LAN endpoint named “Audit Roku”. It demonstrates the app’s connection and foreground-service lifecycle; it is not a recording of a physical television.

Open or download the video

  1. The user selects a TV and sends a remote command.
  2. The user leaves the app. The ongoing “TV Remote Running” notification identifies the active session.
  3. Tapping the notification returns to the same connection; another remote command reaches the test endpoint.
  4. Turning on airplane mode removes Wi-Fi connectivity and ends the foreground service.

The service starts only after a user-initiated TV connection succeeds. It preserves the remote session while switching apps and stops when the network or app session ends. No login is needed to view this demonstration.
